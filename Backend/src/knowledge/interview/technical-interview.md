# Technical Interview Preparation Guide

## Purpose of a Technical Interview

A technical interview evaluates a candidate's understanding of technical
concepts, problem-solving ability, coding skills, and ability to explain
technical decisions.

Preparation should focus on understanding concepts rather than memorizing
answers.

## Programming Fundamentals

Candidates should understand the fundamentals of the programming language
used in their target role.

Important areas can include:

- Variables and data types
- Functions
- Scope
- Arrays
- Objects
- Strings
- Loops
- Conditional statements
- Error handling
- Asynchronous programming
- Common data structures
- Basic algorithms

## JavaScript Fundamentals

For JavaScript-based roles, candidates should understand:

- var, let, and const
- Functions
- Arrow functions
- Scope
- Closures
- Hoisting
- Destructuring
- Spread and rest operators
- Promises
- async/await
- Event loop
- Array methods
- Objects
- Modules

Candidates should be able to explain concepts using simple examples.

## React Interview Topics

React preparation can include:

- Components
- Props
- State
- JSX
- Conditional rendering
- Lists and keys
- useState
- useEffect
- useContext
- Custom hooks
- Component re-rendering
- Forms
- API integration
- Component organization

Candidates should be able to explain why a particular React approach was used
in their project.

## Node.js and Express

Important topics include:

- Node.js runtime
- npm
- Modules
- Express routing
- Middleware
- Request and response objects
- Error handling
- REST APIs
- Environment variables
- HTTP methods
- HTTP status codes

Candidates should understand the request flow through an Express application.

## MongoDB

MongoDB preparation can include:

- Documents
- Collections
- CRUD operations
- Queries
- Schema design
- Indexes
- Aggregation
- Mongoose
- Relationships and references

Candidates should understand how their application communicates with MongoDB.

## Authentication

Common authentication concepts include:

- Authentication vs authorization
- Password hashing
- JWT
- Cookies
- Sessions
- HTTP-only cookies
- Protected routes
- Token expiration

Candidates should be able to explain the authentication flow used in their
projects.

## REST APIs

Candidates should understand common HTTP methods:

- GET
- POST
- PUT
- PATCH
- DELETE

They should also understand common status codes such as:

- 200
- 201
- 400
- 401
- 403
- 404
- 500

## Project-Based Questions

Interviewers may ask:

- Why did you choose this technology?
- How does your application work?
- What was the hardest problem you solved?
- How did you design your API?
- How does authentication work?
- How is data stored?
- What would you improve?
- What bugs did you encounter?
- How did you deploy the application?

Candidates should be able to explain their own projects clearly.

## Coding Practice

Coding preparation should include problems involving:

- Arrays
- Strings
- Hash maps
- Searching
- Sorting
- Two pointers
- Basic recursion
- Stacks
- Queues

The goal should be to understand the approach and explain the reasoning.

## Technical Interview Checklist

- [ ] Programming fundamentals reviewed
- [ ] Target technology fundamentals reviewed
- [ ] Common interview questions practiced
- [ ] Coding problems practiced
- [ ] Projects can be explained clearly
- [ ] Authentication flow can be explained
- [ ] Database design can be explained
- [ ] API architecture can be explained
- [ ] Deployment process can be explained
