# Resume Writing

A technical resume should clearly communicate the candidate's skills,
projects, experience, education, and relevant achievements.

## Technical Skills

List relevant programming languages, frameworks, databases, tools,
and technologies that the candidate actually knows.

## Projects

Projects should mention:
- Project name
- Technologies used
- Problem solved
- Key features
- Candidate's contribution
- GitHub or live link when available

## Experience

Experience should describe:
- Role
- Organization
- Responsibilities
- Technologies used
- Results or measurable impact when available

## Resume Quality

A resume should be:
- Clear
- Concise
- Easy to scan
- Relevant to the target role
- Free from unsupported or fabricated claims
