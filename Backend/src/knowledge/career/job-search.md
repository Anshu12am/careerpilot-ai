# Job Search Guide

## Define the Target Role

A focused job search starts with a clear target.

Examples:

- Software Developer Intern
- Frontend Developer Intern
- Backend Developer Intern
- Full-Stack Developer Intern
- Junior Software Developer

The target role helps determine which opportunities are relevant.

## Analyze Job Descriptions

Before applying, review the job description carefully.

Look for:

- Required skills
- Preferred skills
- Programming languages
- Frameworks
- Databases
- Experience requirements
- Education requirements
- Responsibilities

Compare these requirements with the candidate's actual skills and experience.

## Resume Matching

The resume should highlight experiences and skills that are genuinely relevant
to the target position.

Important keywords from a job description can be reflected naturally when they
accurately describe the candidate's experience.

Candidates should never add technologies they do not know simply to match
keywords.

## Application Tracking

Keep track of applications using a simple system.

Useful information includes:

- Company
- Position
- Application date
- Job link
- Application status
- Interview date
- Follow-up date
- Notes

Tracking applications helps prevent missed follow-ups.

## GitHub Profile

For technical roles, GitHub can provide evidence of practical work.

Important repositories should:

- Be easy to find
- Have clear README files
- Use understandable project structure
- Avoid exposed secrets
- Explain setup instructions

## LinkedIn Profile

A professional profile should clearly communicate:

- Target role
- Technical skills
- Projects
- Education
- Relevant experience
- Portfolio or GitHub links

Profile information should remain consistent with the resume.

## Networking

Networking can help candidates learn about opportunities and understand
companies and roles.

Useful approaches include:

- Connecting with professionals
- Participating in technical communities
- Attending career events
- Participating in hackathons
- Contributing to open-source projects

Communication should remain professional and respectful.

## Follow-Up

When appropriate, candidates can follow up after an application or interview.

A follow-up message should be:

- Short
- Professional
- Relevant
- Respectful of the recipient's time

## Evaluate Opportunities

Candidates should evaluate opportunities based on factors such as:

- Role responsibilities
- Learning opportunities
- Technology exposure
- Mentorship
- Work environment
- Location or remote options
- Compensation when relevant
- Growth opportunities

## Job Search Checklist

- [ ] Target role defined
- [ ] Job description reviewed
- [ ] Resume updated
- [ ] Relevant projects selected
- [ ] GitHub profile reviewed
- [ ] LinkedIn profile updated
- [ ] Application submitted
- [ ] Application tracked
- [ ] Interview preparation started
- [ ] Follow-up completed when appropriate
